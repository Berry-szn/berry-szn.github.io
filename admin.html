Site editor

How this works. Everything on your site comes from assets/content.js. Edit the fields below, press Download content.js, and replace the file in your repository. Nothing is uploaded anywhere and nothing needs a server.

Adding an image or screenshot. Drop the file into photos/ or shots/ in the repository, then type its path here, for example shots/my_tool.png. Same for audio in audio/.

If a field asks for a path and you leave it blank, that image is simply not shown.
